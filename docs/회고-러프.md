## **㈜ 메비츠 현장실습(인턴십)** 2024년 6월 24일 - 2024년 7월 19일

총 4주간의 인턴십이었고

회사의 실무적인 기여를 한건 아니고, 대표님께서 개인 프로젝트 과제를 내주셨어 풀스택 개발 프로세스 (서비스의 생애주기) 역량을 기르고 이에 대한 경험을 해보라는 의미로 내주셨었는데

우선 주제는 게시판 커뮤니티를 만들어라 그런데 지금 서비스중인 게시판의 문제점이나 아쉬운점 개선할만한 부분을 생각해보고 이를 개선하는 아이디어의 게시판을 기획해보고 개발해보라고 하셨어

나는 Garela Community라는 이름으로 템플릿 기반 게시글 작성이 가능한 커뮤니티를 주제로 개발을 진행했었지

내 기억상 1~2주간은 기본적인 게시판의 CRUD 및 로그인/회원가입 구현을 진행하는 요구사항을 주셨었고,
3~4주간은 서비스에 챗봇을 도입하는 것이었는데 대표님께서 벡터 DB에 대한 개념을 소개해주시고 랭체인 프레임워크를 활용해서 게시판 서비스의 데이터를 기반으로 해서 답변해주는 챗봇을 만들어보라 해주셨어

나는 그래서 게시판에 업로드된 게시글들의 내용을 기반으로 답변해주는 챗봇 개발을 해보았던걸로 기억해

기술스택은 React+Vite, TypeScript, Recoil, React Router, Styled Components, Nodejs, Express, openai api(챗봇), LangChain(파이썬), s3 storage(이미지 업로드를 위해)

당시에 기술적으로는 솔직히 드러내기 부족한 프로젝트야 jwt 기반 인증을 구현하긴 했으나, 실제 이메일 인증도 없었고, OAuth도 도입안하고, 토큰도 액세스토큰만 발급받아 사용했었어.

그나마 좀 막혔던 부분은 당시에 에디터를 Quill Editor를 사용했었는데 에디터에서 이미지를 첨부하더라도 이게 업로드되면 에디터는 마크다운 기반으로 작성이 됐는데, 이미지첨부시에 이미지의 이름의 길이가 엄청 길어서였나? 그래서 본문 데이터의 크기가 너무 길어져서 문제가 생겼었는데, 해결책으로 S3 Storage로 이미지를 업로드하고 그 업로드한 이미지의 url을 기반으로 이미지를 렌더링하게끔 그렇게 구현했던게 기억이 나

아마 당시 참고했으리라 추측되는 관련 블로그 포스팅이 있어 https://12ahn22.tistory.com/entry/Quill-%EC%97%90%EB%94%94%ED%84%B0-%EC%9D%B4%EB%AF%B8%EC%A7%80-%EC%B2%98%EB%A6%AC%ED%95%98%EA%B8%B0

아래는 당시 작성했던 관련 코드 upload 관련 

```markdown
const express = require('express');
const router = express.Router();
const multer = require('multer');
const { S3Client } = require('@aws-sdk/client-s3');
const { Upload } = require('@aws-sdk/lib-storage');
const path = require('path');
const fs = require('fs');

const s3 = new S3Client({
  region: process.env.AWS_REGION,
  credentials: {
    accessKeyId: process.env.AWS_ACCESS_KEY_ID,
    secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY,
  },
  logger: console // 디버깅 정보를 콘솔에 출력
});

// Multer 설정
const storage = multer.diskStorage({
  destination(req, file, cb) {
    cb(null, 'public/uploads');
  },
  filename(req, file, cb) {
    const ext = path.extname(file.originalname);
    cb(null, path.basename(file.originalname, ext) + Date.now() + ext);
  },
});

const upload = multer({ storage: storage });

router.post('/upload-image', upload.single('image'), async (req, res) => {
  const file = req.file;
  if (!file) return res.status(400).send('No file uploaded.');

  try {
    const uploadParams = {
      Bucket: process.env.S3_BUCKET_NAME,
      Key: `images/${Date.now().toString()}${path.extname(file.originalname)}`,
      Body: fs.createReadStream(file.path),
    };

    const upload = new Upload({
      client: s3,
      params: uploadParams,
    });

    const result = await upload.done();
    fs.unlinkSync(file.path); // 로컬 저장소에서 파일 삭제
    const imageUrl = `https://${process.env.S3_BUCKET_NAME}.s3.${process.env.AWS_REGION}.amazonaws.com/${uploadParams.Key}`;

    res.status(200).json({ url: imageUrl });
  } catch (err) {
    console.error("Error uploading image:", err); // 에러 메시지 출력
    res.status(500).send(err.message);
  }
});

module.exports = router;

```
